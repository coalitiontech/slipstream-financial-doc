Header, footer and menus

Header

Open Appearance → Customize → Header. Available settings include:

  • Logo and sticky header.
  • Header CTA label and URL.
  • Header email link.
  • Phone display text and phone link.

Update the visible phone number and its tel: link together. The email link uses a mailto: address.

Footer

Open Appearance → Customize → Footer to edit the about/blurb text, primary and secondary CTA labels/URLs, support email, sales email and copyright line. The theme also uses shared logo and phone settings.

Preview the result and use Publish to save Customizer changes.

Navigation

Open Appearance → Menus, choose the menu and edit its links. Drag child items beneath their parent to create dropdown items, then save.

The theme registers these menu locations:

Location Purpose
Primary Menu Header navigation
Footer — Knowledge Base Footer knowledge links
Footer — Payment Solutions Footer solution links
Footer — Legal Footer legal links
Footer Menu (legacy) Compatibility location; confirm usage before assigning

Check location assignments under Manage Locations. Header/footer buttons are controlled in the Customizer, separately from menu links.
